# 📱 スキマプラス

「5分だけ時間がある。でも何をしよう？」

そんなスキマ時間を有効活用するために開発したiOSアプリです。

あらかじめ登録したタスクの中から、ユーザーが選択したスキマ時間に応じて取り組むタスクを提案します。

個人開発として、**企画・仕様検討・実装・実機テスト・App Store申請・公開**まで一連の工程を経験しました。

---

## 🎯 アプリ概要

スキマプラスでは、ユーザーがタスクと優先度を登録し、

**5分 / 10分 / 15分**

の中から現在使える時間を選択すると、条件に合ったタスクを提案します。

「少し時間が空いたけれど、何をするか考えているうちに時間が過ぎてしまう」

という課題を解決することを目的として開発しました。

---

## ✨ 主な機能

- タスクの登録・管理
- タスクごとの所要時間設定
- 優先度設定
- 5分 / 10分 / 15分からスキマ時間を選択
- 条件に合ったタスクを自動提案
- 同一優先度の場合はランダムに提案
- 実行したタスクの履歴保存

## 🧪 Testing / QA

開発中は、実際のiPhoneを使用して動作検証を行いました。

主に以下の項目を確認しています。

- タスク登録・編集時の動作
- スキマ時間選択時のタスク提案
- 優先度に基づく提案結果
- 同一優先度でのランダム選択
- 履歴の保存・表示
- アプリ再起動後のデータ保持
- UI表示・レイアウト
- 修正後の再テスト

不具合が発生した場合は、再現条件を確認し、原因を切り分けたうえで修正・再テストを行いました。
